今天搭好了自己的博客,记录一下过程:

- 最开始用纯静态 HTML + Markdown,不依赖服务器
- 文章托管在 GitHub 公开仓库
- 网址通过 GitHub Pages 免费访问

> 不用花一分钱,也能拥有自己的博客。

后来换成了 Next.js 博客系统:毛玻璃风格、自带后台管理、支持 Markdown 沉浸式写作,部署在 Vercel 上,更新全自动。
